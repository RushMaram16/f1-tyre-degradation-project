# F1 Tyre Degradation & Lap Time Prediction

## Overview
This project models tyre degradation and predicts lap time performance in Formula 1 using real race data.

It analyzes how tyre wear, track conditions, and race dynamics impact lap times.

---

## Features
- Tyre degradation modeling across laps
- Lap time prediction
- Multiple dataset iterations (v1, v2, v3)
- Data analysis using real F1 telemetry

---

## Datasets
- laps_dataset_v1.csv
- laps_dataset_v2.csv
- laps_dataset_v3.csv
- monza_race_laps.csv

---

## Approach
- Data cleaning and preprocessing
- Feature engineering (lap number, tyre wear, etc.)
- Exploratory Data Analysis (EDA)
- Model development and evaluation

---

## Tech Stack
- Python
- Pandas
- NumPy
- FastF1
- Jupyter Notebook
